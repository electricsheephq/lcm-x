- Changed: Known limit (#2116, v0.31): if a reply reaches LCM-X without its host timestamp and the host replaces it below LCM-X's saved position (an edit-resend in a long session), the replacement is not stored while the session runs. A restart stores it, together with copies of the rest of the session's unstamped replies (#2479). Replies that carry their host timestamp, as Hermes sends them unless a session has no database or a transcript write failed, are stored.
