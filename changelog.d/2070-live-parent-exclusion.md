- Fix: a delegated child of a session excluded by `LCM_IGNORE_SESSION_PATTERNS` (or the stateless patterns) is no longer stored on the clone and prototype routes after the excluded session rotates by compression (#2070). The parent check now asks the engine bound to the parent in this process; it refuses only when that live binding is excluded and no other live engine holds a normal binding of the same id, and any doubt falls back to the pattern check, so a normal parent's children are always stored. A parent whose engine has already ended falls back to the pattern check as before.
