- Fix: A delegated child's tool call whose arguments hold an inline encoded payload, or a list-content row whose part holds one, is no longer stored a second time at the next handover (#2559). The session-end compare now reads tool-call arguments as parsed JSON, the form the replay identity already uses, and restores inline payloads in list content part by part. Arguments with a duplicate key, and arguments that are not valid JSON, stay text and compare with edge whitespace trimmed; a payload held in an argument key is restored before the keys are sorted, unless two keys of one object would restore to the same key. The same change stores the final reply in the matching off-current session-end cases of #2543.
