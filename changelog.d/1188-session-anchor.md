- New: Opt-in `LCM_RECALL_GUIDANCE=v2` adds guidance for recall across conversations, answer-ready `sessions_delivered` and `sessions_in_pool` counts, and advertised anchor windows for `lcm_load_session`. `LCM_RECALL_SESSION_HINTS=true` adds callable hints using each anchor row's own session ID, including after summary rollover. Both settings preserve existing behavior by default and leave internal recall unchanged. The `lcm-x mcp` reader now serves the session-delivery `lcm_recall` schema when `recall_delivery_unit=session`; v2 guidance omits the hits-only provenance instruction in that mode.
- With `detail="answer_ready"`, compare `provenance.answer_ready.sessions_delivered` with `sessions_in_pool`; when fewer sessions were delivered than are in the pool, call again with `exclude_session_ids` set to the sessions already read. When a hit carries a `session_hint`, use it to read around the hit. Failed hint reads omit only that hint. Anchor continuation uses the scanned window boundary when filters or the cursor leave no rows, and returns a null cursor when no matching rows remain.
