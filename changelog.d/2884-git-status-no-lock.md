- Fix: The plugin's git identity probe for `/lcm status` and `/lcm doctor` in a source checkout now runs git with the `GIT_OPTIONAL_LOCKS=0` environment variable, so a probe stopped at its one-second timeout no longer leaves an empty `index.lock` that makes the next git write in that checkout fail (#2884). The reported commit, branch, dirty flag and remote are unchanged, including on git older than 2.15, which ignores the variable.
