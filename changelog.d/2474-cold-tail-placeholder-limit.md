- Changed: Known limit (#2474): on a home where ignore patterns are or were configured (none are set by default), after a busy session end, if the session's last view holds one of LCM's own placeholders for an ignored message and the host undoes and resends a message, the earlier copy of that message can be lost. The session end logs that a retry is pending, but the later drop is not counted or reported. v0.29.x lost it on the same trigger too, but warned at session end that final messages might be missing. A fix is planned for v0.30.x.
