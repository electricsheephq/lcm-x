- New: opt-in `recall_snippet_window_hits` (`LCM_RECALL_SNIPPET_WINDOW_HITS`, default `0`) gives the first N message-excerpt recall hits from chunk (vector) or keyword search windows of up to 2,400 characters, centred on the matched chunk, else the keyword match, else the query match, with window metadata; shorter messages come back whole. Proactive recall ignores the setting; ranking, selection and `detail="answer_ready"` and `delivery_unit="session"` delivery are unchanged. Larger windows can fit fewer hits under `response_char_cap`, reported as `response_cap_truncated`; skipped window reads preserve original snippets and report `snippet_window_skipped` (`deadline` or `read_error`).
