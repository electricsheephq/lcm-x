- Fix delegated-child and session-end saved-output comparison (#2539). Two bare markers are the same row only when their text is byte-identical. A marker and a stored recovered result are the same row when the marker's path and character count equal the ones recorded at ingest and the marker's preview is exactly the start of the stored content. The marker's boilerplate wording is not part of that identity. A stored row takes a marker identity only from its own marker: when its payload's recorded marker source is not unambiguously this row's (a shared payload, a plain row, a marker with another path), the row compares by content. An empty preview takes the content fallback. An exact preview mismatch after ingest redaction compares unequal without transforming the preview. The marker rule holds on the positional and pairwise routes (live child store, off-current end, cold tail). The counted fallbacks compare by content: a missing or rewritten file, or a reused call id, gives one extra copy there, never a loss.
