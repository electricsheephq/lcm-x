# Calibrated D2 instrument (#1824)

`d2_driver.py --config pins.json --out NEW_DIRECTORY [--aa] [--option A]`
runs the fixed comparison through `run_pmw_cell.sh`. The comparison directory must
not exist. The driver never resumes a stopped comparison or starts a second look.
Option B plans 54 slots; option A plans 24 and requires a nonempty
`funding_refusal` pointing to the release manager's ruling. Option A is a coarse
regression screen, never non-inferiority. `--aa` requires identical build SHAs.

The config has this shape (replace example values with the reserved identities):

```json
{
  "material": "material/track-s-v3",
  "expected_instrument_hash": "paste the one-line command output below",
  "comparability_ruling": null,
  "instrument_hash_ruling": null,
  "builds": {
    "comparison": {"worktree": "builds/previous", "sha": "EXACT_COMMIT", "arm": "LCMX-fleet-120s-c24k"},
    "candidate": {"worktree": "builds/candidate", "sha": "EXACT_COMMIT", "arm": "LCMX-fleet-120s-c24k"}
  },
  "summary": {"provider": "glm", "model": "glm-5.3", "effort": "low", "tier": "default"},
  "reader": "glm-5.3",
  "policy": {"arm": "LCMX-fleet-120s-c24k"},
  "funding_refusal": null
}
```

Use absolute worktree/material paths when invoking from another directory.
The existing producer's environment prerequisites still apply, including `PY`,
`GLM_API_KEY` and `FACTS_FLOOR`. Credentials are inherited, never stored in pins.
The policy arm must explicitly select low summary effort. The calibrated D2 route
is GLM summaries plus the GLM reader. A changed route (Codex Sol summaries) requires
a `comparability_ruling`; D7 keeps its Codex default. The producer's
`SUMMARY_LANE` selection is explicit in D2 and defaults to `codex-sol` otherwise.
Material manifests and fact IDs, both clean build identities, all tracked
instrument files, route, reader, policy and retry behavior are saved before the
first replay. Producers independently recheck clean build and kit identities.
Obtain the hash before the run with
`python3 bench/instruments/compaction_probe/track_s/decision/d2_driver.py --config pins.json --print-instrument-hash`.
This validates the kit/config and prints one hash without requiring the expected hash or starting a run.
Paste it into `expected_instrument_hash` before preparation. A mismatch requires
`--instrument-hash-ruling URL`; the separate `--comparability-ruling URL` covers route changes.
Both rulings are recorded in pins; an old route ruling cannot waive a hash mismatch.
Option A cannot use `--aa`.
Instrument and manifest-listed material bytes are rechecked before every launch
and scoring, including newly untracked files under the kit. Drift makes the comparison INCONCLUSIVE pending a comparability ruling.

`run_pmw_cell.sh [k [attempt]]` accepts k=1..9 and positive attempt IDs. Its
argument-free paths and commands remain the original r1 shape. Other calls use
`OUT/replay-r<k>[-a<attempt>]`; run labels and logs include the same suffix. An
existing reservation, run, log or scoring directory is refused. The driver gives
each labeled slot and attempt its own output directory and preserves both
attempts. `score_decision.py --runs 1 2 ... 9 [--attempt 2]` and
`pmw_read.py --runs 1 2 ... 9 [--attempt 2]` can also select replay indices in a
single conventional run root. Their original defaults remain two and one runs,
respectively. D7 continues to use the original default path and analyzer.

`ledger.json` retains one row per planned slot. Row/attempt times are elapsed
seconds from driver entry, including setup and scoring; wall timestamps remain
in producer receipts. Candidate occupies slot 1 on odd k and slot 2 on even k,
including A/A. At most two producers run together, one for each labeled arm.
Invalid attempts can be replaced once per slot and at most twice overall;
valid scores never trigger a replacement. Missing, partial and truncated inputs
remain in the denominator. A usage/rate marker terminates active producers and
stops further launches without replacement, including before the first post-launch sleep.
SIGTERM and SIGHUP enter the interrupt cleanup path, stop producer groups, and record
`interrupted` with the signal name; prior handlers are restored on exit.
Inherited ignored signals stay ignored: a nohup-launched run ignores SIGHUP.
After the first handled signal, TERM, HUP and INT are ignored until cleanup finishes.
A second Ctrl-C during cleanup is ignored, including cleanup after an exception.
Log monitor errors retain at most 50 entries, with the rest counted in `monitor_errors_dropped`.
At six elapsed hours every
unfinished slot is marked and the raw verdict is INCONCLUSIVE.

For run control, the GLM reader and summary lane retry transient HTTP 429s up to
three times, using numeric Retry-After (capped at 120 seconds) or waits of 30, 60,
then 120 seconds. Persistent or quota/usage limits still stop the run. Receipts
record per-call `throttle_retries`; reader readback also retains `throttle_retries_total`.
All attempts and waits share the caller's timeout budget; a retry needs more than
one second left after its wait, otherwise `throttle_deadline_stop` marks the terminal
429. Reader per-ask counts sum native/fallback requests and accompany each reader-call receipt.

Set `FMP_RESULT_CARD_TOOL` to the installed `bench-card.py` before running.
Preparation checks that this file exists before launching any producer; printing
the instrument hash does not require the card tool.
Completed runs emit and validate `RESULT-MANIFEST.json` and `RESULT.md`, retaining
`result.json` and `result.md` (the Markdown names alias on case-insensitive filesystems).
The manifest retains pins, ledger and replay artifacts for re-scoring; publication
remains a release-manager gate.

`result.json` and `result.md` contain the raw verdict, an empty disposition, the
cp-304 interval, cp-176 placebo, run permutation, per-occurrence McNemar and
per-seed spreads. Option A enumerates every 4+4 allocation within every seed;
option B uses 20,000 seeded allocations. The no-dependency Student-t CDF uses
the [NIST density](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3664.htm)
with a trigonometric substitution and integration-by-parts recurrence, then
bisects to obtain the quantile. Fixtures cross-check density quadrature and
tabulated critical values. Comparisons within 1e-12 of a threshold are treated
as equality, avoiding floating-point roundoff at the predeclared boundaries.

The offline normal simulation tests only the complete-valid cp-304 lower-bound
rule, matching the calibration packet's Gaussian model. It excludes the
cp-176 compound condition, the A/A point cap, provider failures, retries and
elapsed stops. It is instrument proof, not the required prospective A/A or a
measurement of any release's facts kept. Independent review, remote CI and
release-manager disposition remain separate gates.

The stdlib permutation sampler preserves NumPy's integer-seed SeedSequence and
PCG64 stream, including its 53-bit uniform ordering. References:
[SeedSequence](https://github.com/numpy/numpy/blob/v2.4.2/numpy/random/bit_generator.pyx),
[PCG64](https://github.com/numpy/numpy/blob/v2.4.2/numpy/random/src/pcg64/pcg64.h).
